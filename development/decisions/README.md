# Decision Log

Decisions that concern only this work. Decisions that shape The Science Infrastructures as a whole are in [its log](https://github.com/huangwanhong-maker/The-Science-Infrastructures/tree/main/development/decisions); the work's attachment to the infrastructure as a submodule, and the domains it brings forward, are to be recorded there.

- Records are numbered and are never rewritten.
- To change a decision, write a new record that supersedes or amends the old one, and update the old record's status to point to the new one.
